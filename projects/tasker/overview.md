# tasker

个人任务管理桌面 app：管任务 + 记时间 + 按日期/优先级组织每日工作节奏。

## 目标

- 单人本地使用，不做多端同步
- 任务的生命周期由**时间记录**驱动（不是靠手动改状态）
- 每天开工前能一眼看到"今天该做什么"，收工时能看到"今天做了什么"
- 磁盘存储对人友好：可用文本编辑器直接看/改

## 领域模型

### 任务 Task
- 标题
- 描述：markdown/富文本（大字段，单独文件）
- 分类：日常跟进 / 会议 / 我的任务 / Platform·Chaos test / 其他；每个分类可在设置里指定颜色（甘特图色条用），不指定则按分类顺序取 8 槽位调色板色
- 状态：从各天关联下的时间记录汇总计算，不独立存储
  - 无时间记录 → 未开始
  - 有开始未结束 → 进行中
  - 最后一条时间记录带 `完成` 标志 → 完成
  - 最后一条带 `再开始` 标志 → 回到进行中

### 任务集合 TaskCollection + Membership
- **某天集合**：带日期，可被用户标记为已完成（表示这一天已复盘/无需再回看）；若之后有任务新加入该日期集合，自动清除该日期完成标记
- **Backlog（虚拟）**：未完成任务；循环任务永远出现
- **所有日期（虚拟视图）**：把所有某天集合按日期升序排开，再把 Backlog 作为最后一个分组；每个分组内再按分类分组。同一任务关联了几天就出现几次，每一行的状态 / 优先级 / 当前标按该行所属那天的上下文计算（Backlog 行按 Backlog 上下文）。状态开关（当前 / 隐藏已完成 / 隐藏未开始）逐天应用，过滤后为空的天不显示

任务通过 **Membership.dayAssignments**（任务↔某天的关联对象）归属日期集合。一个任务可属于多天。
- `day`：日期
- `priority`：今天必达 / 重要 / 正常 —— **属于某天关联，不属于任务本身**
- `isCurrent`：该任务在这一天是否被标记为当前
- `entries`：这一天实际发生的时间记录 —— **属于某天关联，不直接挂在任务全局下**

任务归属和优先级都通过列表**右键菜单**操作，不作为详情里的常规属性编辑（除详情顶部的优先级快捷编辑外）。有时间记录的日期关联不能直接移除，避免误删历史记录。

### 时间记录 TimeEntry
- 挂在 `DayAssignment.entries` 下，表示某任务在某天的实际工作记录
- 标题（这段活是干什么的）
- 类型（工作类型）
- 开始时间 / 结束时间（都可编辑）
- 可选阶段性标志：`完成` / `再开始`

## 技术选型

- **平台**：macOS Native（默认 Swift + SwiftUI；未来跨平台再议）
- **存储**：本地磁盘
  - jsonl 存结构化数据（任务元信息、时间记录）
  - json 存日期集合完成标记等轻量全局状态
  - markdown 存描述等大字段（每个任务一个 `.md` 文件）
  - 默认根目录 `~/Documents/tasker/`；用户可在设置里改，路径存 `UserDefaults`（key `tasker.dataRoot`）
- **代码位置**：`app/tasker/`（SwiftPM 工程，与本项目文档目录 `projects/tasker/` 平级）
- **内存模型**：
  - 启动时全量加载
  - 内存改动 → 同步写盘（写盘前先校验磁盘版本，避免覆盖手改）
  - 定时扫盘（~10s）把外部手改同步回内存
- **代码风格**：DDD（聚合根 = Task；DayAssignment 是任务↔日期关联；TimeEntry 作为 DayAssignment 内实体；TaskCollection 是查询/视图）

## UI 布局

- 左侧栏：顶栏 = 范围下拉（`ListScope`：某天/当天 · Backlog · 所有日期）+ 紧挨其右的新建任务按钮（Cmd+N）+ 状态开关（当前 / 隐藏已完成 / 隐藏未开始）；底栏 = 统计 / 甘特图 / 设置 / 刷新
  - 某天 / Backlog：按分类分组
  - 所有日期：天 → 分类 → 任务，Backlog 作为最后一天；选中某行时记住该行所属天作为详情页上下文（`contextFilter`）
    - 每个天分组是醒目的标题行（粗体 + 任务数），可单独折叠 / 展开；顶部有一键按钮：有展开的就全折叠，全折叠了就全展开（折叠状态仅存内存，不落盘）
- 右侧详情页的状态徽章、优先级 / 当前控件、时间记录列表都针对 `contextFilter`（某天 / Backlog 模式下即当前范围；所有日期模式下是选中行所属的天）
- 右侧：任务详情（markdown 编辑）+ 时间记录列表
- **统计窗口**（侧栏底部 `chart.bar` 按钮）：日期区间内按天 → 任务 → 记录的汇总与 0–24h 概览条
- **甘特图窗口**（侧栏底部 `calendar.day.timeline.left` 按钮，紧挨统计按钮）：独立窗口，选某一天（日期选择器 + 前/后一天 + Today），日期右侧有新建任务按钮，新任务直接归属当前选中的那天并自动进入选中任务模式
  - 左列：该天的任务，按分类分组（分类标题带固定色块，任务行标题前带该天优先级 emoji 前缀，与侧栏一致，行尾带当天状态标与当天总时长）
  - 右侧：时间轴，顶部小时刻度（按像素密度自动决定标签间隔与 15/30 分钟小刻度），今天显示红色"现在"线；可见时段默认自动覆盖当天所有记录前后各留 1 小时（无记录 08–19），可用 Stepper 手动调整、Auto 复位
  - 每条已开始的时间记录是一个色条（颜色 = 分类色：设置里指定 > 按顺序的调色板槽位色 > 灰），标题始终可见：条够宽写在条内，太窄则从条左边缘起向右书写（允许超出条）；未结束的记录用虚线框画到"现在"
  - **直接编辑规则**（领域层 `TimelineGrid`，最小刻度 5 分钟）：拖条身 = 整体平移（起点吸附到格，时长不变）；拖左/右边缘 = 改起点/终点（吸附到格，起终点至少相差 1 格）；在空白处拖 = 新建一段记录（优先填入该天尚未开始的占位记录，否则新建）；时间段不能越出当天 0:00–24:00；拖未结束记录的右边缘 = 给它一个终点
  - 两种选中：点任务名 = 选中任务，行高亮，底部变成任务编辑条（标题 / 分类 / 该天优先级）；点色条 = 选中记录，底部显示任务名、可直接编辑的记录标题、起止 DatePicker、时长；DatePicker 输入同样吸附到 5 分钟格
- **UI 文案统一英文**：所有按钮 / 菜单项 / tooltip / 星期名 / 日期格式化输出等面向用户的可见文字都用英文（`Day.weekdayLabel` 默认 `en_US`，`MiniCalendarView` 表头强制 `en_US`）；代码注释、log、overview 等开发文档保持中文

## 明确不做

- 云同步 / 多端
- 多人协作 / 共享
- 通知 / 提醒（先不做，之后可加）
- 手动改任务状态（状态永远是时间记录算出来的）
